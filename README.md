# jvs：頻道專用 Discord 助理

在指定頻道 @它說一句話，就會幫你設提醒、記東西、計時、報天氣。
句子怎麼講都可以（「明天提醒我…」「提醒我明天…」「…明天提醒我」都行），**完全用規則判斷，不用 LLM**。
每個人的提醒和記事各自分開；另外有一個**只有你能進**的設定網頁。

```
Discord 頻道 ──@jvs──▶ router（關鍵字分類）──▶ timeparse（中文時間解析）
                               │                          │
                               ▼                          ▼
                         SQLite（提醒／記事／設定）◀── 排程（每 15 秒）──▶ 頻道 @你 + 按鈕
                               ▲
                 設定網頁（127.0.0.1:8080）◀── Cloudflare Tunnel + Access ◀── 你
```

## 會做的事

| 功能 | 說法範例 | bot 的回法 |
|---|---|---|
| ⏰ 提醒 | `明天下午3點提醒我交報告`、`這幾天提醒我訂車票`、`10分鐘後叫我關火` | 照你的話回：「好，這幾天提醒你訂車票。」下面小字附實際時間 |
| 🔁 重複 | `每天早上8點提醒我吃藥`、`每週三和週五提醒我運動`、`每個月1號`、`每月底` | |
| 🔢 次數／期限 | `每15分鐘提醒一次，共四次`、`每天提醒我背單字，持續一週`、`只問今天`、`提醒我三次` | |
| 🤔 時間不確定 | `有空的時候提醒我…`、`出門前提醒我…`、`吃完飯後…`、`之後提醒我…` | 「你是指什麼時候？」附快選按鈕，也可以直接打字回 |
| ☔ 看情況 | `下雨天提醒我把雨衣拿出來`、`發薪日提醒我存錢` | 每天看預報；發薪日沒設定會先問你幾號 |
| 👥 提醒別人 | `明天中午提醒 @小明 開會` | |
| 🔔 提醒響了 | 按鈕：**收到**（完成）／**等等做**（1.5 小時後）／**明天再說**（隔天下午） | 沒按的話會再提醒 |
| ↩️ 回覆 bot 訊息 | 直接回覆那則提醒（不用 @）：`不用了`／`取消`、`好`、`晚點`、`後天` | 只動那一個提醒 |
| 💤 用說的延後 | `後天再提醒我`、`晚兩個小時再提醒`、`這件事下週一再說`（不用回覆，套用到最近響的那個） | |
| 🗑️ 用說的取消 | `不用再提醒我喝水了`、`刪掉跟報告有關的提醒`、`取消今天所有提醒`、`取消 12` | 先列出來，按「確認」才取消 |
| 🎨 願望清單 | 聊天時說 `我想畫…`、`之後想買…`、`有點想追…`，**不用 @**（預設只聽你） | 簡短回「我記住了」「好～」「要畫！」 |
| 🎲 從清單挑 | `@jvs 我最近可以畫什麼`、`我不知道畫什麼`、`有推薦可以看的嗎` | 挑 5 個：近期的比較常出現，但每一項都會輪到 |
| 📝 記事 | `記住 靈感：…`、`記一下 車停在 B2-37` | |
| ⏱️ 計時 | `計時 25 分鐘` | |
| 🌤️ 天氣 | `天氣`、`台中天氣`；每天固定時間自動貼 | |

### 「從清單挑」怎麼挑
用加權輪流（smooth weighted round-robin）：每問一次，清單裡每一項都加上自己的權重，分數最高的 5 項被挑出來後扣分。
權重 = 1 + 4 × 0.5^(距離最後提到的天數 ÷ 半衰期 14 天)，所以最近提到的累積得快、比較常出現；舊的雖然慢，分數也一直在累積，遲早一定會被挑到。同一件事又提到一次，就會重新變成「最近」。

### 時間怎麼解讀
- 沒講上下午的 1～6 點當下午（「3點」= 15:00）；7～11 點如果今天已經過了，就改成晚上的同一時刻
- 只講日期沒講幾點 → 09:00；「早上／中午／下午／傍晚／晚上」各有預設時刻，都可以在設定頁改
- 「週三」= 這週三，已經過了就是下週三；「下週三」= 下一週的星期三
- 中文數字、全形數字都可以（`三點半`、`１５：３０`）

## / 指令（誰都能用，回覆只有自己看得到）
- `/說明`、`/設定`、`/提醒`（自己的提醒，可編輯）、`/天氣 地點`
- `/清除 範圍`（只有主人）：刪掉這個頻道的訊息，範圍例如 `全部`、`近7天`、`今天`、`最近50則`；也可以直接說「賈維斯 清空這個頻道」「賈維斯 刪掉近七天的訊息」。會先跳確認按鈕，釘選的留著，超過兩週的訊息只能一則一則刪，比較慢
- `/stark says`：賈維斯拿 Stark 的圖回覆一則訊息。可以換圖、填訊息連結（不填就回頻道裡最新一則別人的訊息）、加一句話
- 在訊息上按右鍵 → 應用程式 → **Stark says**：直接回那則，用預設圖

## 設定網頁
長得像 Discord：最左邊選機器人（賈維斯、蔣寶…），旁邊一排分類，每一頁的區塊都先摺起來，點標題才展開。右上角是一鍵更新。

- **記憶**
  - **提醒**：所有人的提醒，可以直接改時間、內容或取消
  - **清單**：想看、想畫、想買、備忘，可以改內容、換清單、刪除、新增
- **回覆**
  - **預設回覆**：bot 會說的每一句話，一行一句；招呼說法可以用 `{時段}` `{名字}` `{天氣}`。下面是圖庫（打招呼、稀有招呼、Stark says），每張圖有代碼可以綁到句子上
  - **自訂回覆**：自訂「誰說的、要不要叫它、有沒有交代事情、包含／不包含哪些詞 → 回哪句或哪組圖」。列表只顯示名稱和關鍵字，點開編輯；勾選框啟用／停用；按住 ⋮⋮ 拖曳調整優先順序（上面的先比對）
  - **吃什麼**：「我要吃什麼」的問題樹、食物庫、觸發詞
  - **表情符號**：看到關鍵字自動幫訊息按表符
- **設定**
  - **設定**：總開關（回應訊息）、功能開關、叫它的方式、預設時刻、延後按鈕、再提醒、天氣、清單
  - 叫它時句子有「幫我／給我／教我／能不能」（「設定 → 叫它」可改）就算要它做事：賈維斯做得到就做，做不到用「聽不懂」那組回
  - **判斷**：bot 怎麼判斷一句話（依順序列出規則和關鍵字），可以試一句
- **一鍵更新**（右上角）：主機跑的版本、GitHub 上最新的版本；按下去就 git pull → 檢查 → 安裝 → 確認服務正常，新版起不來會自動退回上一版（詳見 [docs/SETUP.md](docs/SETUP.md#之後更新程式在設定網頁按一下)）

## 好幾個 bot
`.env` 填了 `JBAO_DISCORD_TOKEN` 就會多跑一個「蔣寶」，同一支程式、同一個設定網頁，資料各自分開（`data/jbao.db`、`data/images-jbao/`）。步驟見 [docs/SETUP.md](docs/SETUP.md#45-加第二個-bot蔣寶)。

蔣寶是「轉介模式」，沒有提醒、清單、打招呼這些功能，設定網頁也只顯示用得到的頁面：
- **轉給賈維斯**：任何人叫蔣寶交代事情（賈維斯會的提醒、天氣、吃什麼、問要不要…，或句子有「幫我／給我／教我／能不能」），蔣寶隨機回一句官腔並 @賈維斯，賈維斯接手照平常流程回覆那個人（不是主人一樣會被拒絕）。說法在「預設回覆」改，可以用 `{任務}`
- **改暱稱**：叫它時講到關鍵字就改自己的暱稱，「設定 → 改暱稱」一行一組 `關鍵字/關鍵字｜暱稱/暱稱`，寫 `原名` 就改回來（賈維斯也能設）
- **打招呼**：只叫名字或「嗨蔣寶」會打招呼，說法和圖在蔣寶的「預設回覆」
- **自訂回覆、表情符號**：跟賈維斯一樣。自訂回覆可以選「全部依序送出」：每一句／每一張各一則訊息（預設帶一條「可愛三連拍」，上傳三張圖就能用）
- **應聲蟲**：有人打「蔣萬安說…」「蔣寶說…」「@蔣寶 說…」（「叫它」裡任何一個名字都行），蔣寶就把後面的話照講一次；@ 不會真的 tag 到人。「設定 → 應聲蟲」開關（賈維斯也能開）
- **互相觸發**：兩個 bot 看得到對方講的話（蔣寶應聲講「賈維斯」，賈維斯會打招呼；自訂回覆、表符也會被對方觸發），但只連一層：因為對方才講的話不會再被接。「設定 → 功能」可以關
- **自己觸發自己**：「設定 → 功能 → 自己講的話也會觸發自己」填幾就最多連幾次（蔣寶預設 10，賈維斯 0）
- **表情符號**可以寫伺服器的自訂表情 `:jibar:`，也可以寫 Discord 內建的 `:milk:`、`:thumbsup:`，或直接貼 🥛
- **Jbao says**：`/jbao says` 和右鍵選單「Jbao says」，用蔣寶「預設回覆」最下面 says 圖庫的圖回覆某則訊息


### 雪豹
`.env` 填 `SNOW_DISCORD_TOKEN`。只有真的 @雪豹 才會回（講到名字、回覆它的訊息都不算）：照洗好的順序發一張圖庫的圖，附一個隨機貓咪顏文字。
- 「假隨機」：整個圖庫洗牌成一輪，一張一張發，同一輪不重複；發完重新洗牌，每輪順序都不一樣、換輪時不會連發同一張；中途新上傳的會插進這一輪
- 每輪發完的那一刻，賈維斯會在它自己的提醒頻道 @你說「雪豹庫存不夠了」（說法可改）
- 設定網頁「預設回覆」可以「📁 選資料夾上傳」整個資料夾、看這一輪還剩幾張、重新洗牌、全部刪除；顏文字一行一個
- 在別人傳的圖片訊息上按右鍵 → 應用程式 → **加到雪豹圖庫**：那則訊息的圖（附件或圖片連結）都加進去，結果只有你看得到。預設大家都能加，「設定」可以改成只有主人
- 防重複用圖片指紋：轉存、縮放、壓縮、換格式的同一張圖也認得出來，右鍵加圖和網頁上傳都會擋

## 測試台（不用連 Discord 就能試對話）
`sim/` 是一個網頁版的模擬頻道，用 [Pyodide](https://pyodide.org/) 在瀏覽器裡直接跑 `reminderbot` 的 Python 程式碼，所以判斷邏輯跟正式 bot **完全是同一份**。
- 可以切換成員（你／小明／小美）、@別人、按按鈕、回覆提醒
- 每句話下面會顯示 bot 怎麼判斷；判斷錯的按「判斷錯了」，在「回報」寫下原意，一鍵複製
- 「時間機器」可以快轉，看提醒什麼時候響、沒按完成會不會再提醒
- 設定和正式設定網頁同一組欄位；天氣用假資料

```bash
python3 sim/build.py              # 產生 sim/dist/（第一次會下載 Pyodide，約 14MB）
cd sim/dist && python3 -m http.server 8000   # 打開 http://localhost:8000
```

## 本機開發
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env   # 填 DISCORD_TOKEN、CHANNEL_IDS
.venv/bin/python -m pytest          # 測試
.venv/bin/python -m reminderbot     # 執行，設定頁在 http://127.0.0.1:8080
```

| 檔案 | 內容 |
|---|---|
| `reminderbot/timeparse.py` | 中文時間解析、重複規則 |
| `reminderbot/router.py` | 關鍵字判斷要做什麼、整理提醒內容 |
| `reminderbot/core.py` | 核心邏輯：收訊息、按按鈕、時間到 → 要做的動作（不碰 Discord） |
| `reminderbot/bot.py` | Discord 轉接層：把 Discord 事件交給 core、把動作送回 Discord |
| `reminderbot/web.py` | 設定網頁 |
| `reminderbot/settings.py` | 可調整的設定與預設值 |
| `reminderbot/weather.py` | 中央氣象署 F-C0032-001 |
| `reminderbot/store.py` | 資料存取（SQLite 正式用、記憶體版給測試台） |
| `sim/` | 測試台網頁 |
| `deploy/` | 安裝腳本、systemd 服務、每日備份、設定網頁的一鍵更新（`web-update.sh`、`jvs-update.path`） |

想讓 bot 聽懂新說法：在 `tests/test_timeparse.py` 或 `tests/test_router.py` 加一個例子，再改對應的規則，直到測試通過。
