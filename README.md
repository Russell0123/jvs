# jvs：頻道專用 Discord 助理

在指定頻道 @它說一句話，就會幫你設提醒、記東西、計時、報天氣。
句子怎麼講都可以（「明天提醒我…」「提醒我明天…」「…明天提醒我」都行），**完全用規則判斷，不用 LLM**。
每個人的提醒和記事各自分開；另外有一個**只有你能進**的設定網頁。

```
Discord 頻道 ──@jvs──▶ router（關鍵字分類）──▶ timeparse（中文時間解析）
                               │                          │
                               ▼                          ▼
                         SQLite（提醒／記事／設定）◀── 排程（每 15 秒）──▶ 頻道 @你 + 按鈕
                               ▲
                 設定網頁（127.0.0.1:8080）◀── Cloudflare Tunnel + Access ◀── 你
```

## 會做的事

| 功能 | 說法範例 |
|---|---|
| ⏰ 提醒 | `明天下午3點提醒我交報告`、`提醒我週五繳電費`、`10/30 晚上8點半 看直播`、`10分鐘後叫我關火`、`記得明天帶傘` |
| 🔁 重複提醒 | `每天早上8點提醒我吃藥`、`每週一三五晚上9點提醒運動`、`平日早上7點半`、`每月5號繳房租`、`每年3月14號`、`每30分鐘提醒我喝水` |
| 👥 提醒別人 | `明天中午提醒 @小明 開會`（也可以 @身分組） |
| 💤 延後 | 提醒響了按「10 分鐘後／1 小時後／明天」，或**回覆**那則提醒說 `@jvs 延後 30 分鐘` |
| 🔔 再提醒 | 沒按「完成」的話，每 30 分鐘再提醒一次，最多 2 次（可調） |
| ⏱️ 計時 | `計時 25 分鐘`、`倒數 1小時30分 泡麵` |
| 📝 記住 | `記住 靈感：…`、`我想看 葬送的芙莉蓮`、`記住 主題：…`、`記一下 車停在 B2-37` |
| 📋 查詢 | `我有哪些提醒`、`我想看什麼`、`列出靈感`、`我的記事` |
| 🗑️ 取消／刪除 | `取消 12`、`取消提醒 3, 5`、`刪除靈感 2`（或按設定成功訊息下的「取消」） |
| 🌤️ 天氣 | `天氣`、`台中天氣`；每天固定時間自動貼（中央氣象署 36 小時預報，會提醒帶傘） |
| ❓ 說明 | `說明` |

### 時間怎麼解讀
- 沒講上下午的 1～6 點當下午（「3點」= 15:00）；7～11 點如果今天已經過了，就改成晚上的同一時刻
- 只講日期沒講幾點 → 09:00；「早上／中午／下午／傍晚／晚上」各有預設時刻，都可以在設定頁改
- 「週三」= 這週三，已經過了就是下週三；「下週三」= 下一週的星期三
- 中文數字、全形數字都可以（`三點半`、`１５：３０`）

## 設定網頁
- **設定**：功能開關、各種訊息格式（`{text}`、`{mentions}` 這類變數）、預設時刻、延後按鈕、再提醒規則、天氣（縣市、時間、帶傘門檻）、記事分類與關鍵字
- **提醒**：所有人的提醒，可以直接取消
- **記事**：所有人的記事，可以直接刪除

Discord 裡沒有任何設定入口。網頁只聽 `127.0.0.1`，外面要連必須經過 Cloudflare Access（或 SSH 轉發）。

## 部署
照 **[docs/SETUP.md](docs/SETUP.md)** 一步一步做：Discord bot → 氣象署 key → Oracle 免費 VM → 一鍵安裝 → Cloudflare 保護設定頁。

## 測試台（不用連 Discord 就能試對話）
`sim/` 是一個網頁版的模擬頻道，用 [Pyodide](https://pyodide.org/) 在瀏覽器裡直接跑 `reminderbot` 的 Python 程式碼，所以判斷邏輯跟正式 bot **完全是同一份**。
- 可以切換成員（你／小明／小美）、@別人、按按鈕、回覆提醒
- 每句話下面會顯示 bot 怎麼判斷；判斷錯的按「判斷錯了」，在「回報」寫下原意，一鍵複製
- 「時間機器」可以快轉，看提醒什麼時候響、沒按完成會不會再提醒
- 設定和正式設定網頁同一組欄位；天氣用假資料

```bash
python3 sim/build.py              # 產生 sim/dist/（第一次會下載 Pyodide，約 14MB）
cd sim/dist && python3 -m http.server 8000   # 打開 http://localhost:8000
```

## 本機開發
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env   # 填 DISCORD_TOKEN、CHANNEL_IDS
.venv/bin/python -m pytest          # 測試
.venv/bin/python -m reminderbot     # 執行，設定頁在 http://127.0.0.1:8080
```

| 檔案 | 內容 |
|---|---|
| `reminderbot/timeparse.py` | 中文時間解析、重複規則 |
| `reminderbot/router.py` | 關鍵字判斷要做什麼、整理提醒內容 |
| `reminderbot/core.py` | 核心邏輯：收訊息、按按鈕、時間到 → 要做的動作（不碰 Discord） |
| `reminderbot/bot.py` | Discord 轉接層：把 Discord 事件交給 core、把動作送回 Discord |
| `reminderbot/web.py` | 設定網頁 |
| `reminderbot/settings.py` | 可調整的設定與預設值 |
| `reminderbot/weather.py` | 中央氣象署 F-C0032-001 |
| `reminderbot/store.py` | 資料存取（SQLite 正式用、記憶體版給測試台） |
| `sim/` | 測試台網頁 |
| `deploy/` | 安裝腳本、systemd 服務、每日備份 |

想讓 bot 聽懂新說法：在 `tests/test_timeparse.py` 或 `tests/test_router.py` 加一個例子，再改對應的規則，直到測試通過。
